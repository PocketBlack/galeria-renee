# Artist Gallery System — Implementation Protocol V1

## Objective

Implement a professional digital gallery for an artist using the existing engine rather than rebuilding the project from zero.

## Inputs required

1. Artist identity
2. Positioning and biography
3. Location
4. Contact channel
5. Hero image
6. Social preview image
7. Favicon
8. Artwork catalog
9. Availability rules
10. Visual direction

## Process

### Step 1 — Discovery

Collect the artist's identity, catalogue and commercial objective.

### Step 2 — Configuration

Populate the Artist Configuration Contract.

### Step 3 — Catalog

Connect the catalog source and validate every image and status.

### Step 4 — Visual adaptation

Adapt the visual layer without modifying core behavior.

### Step 5 — Technical QA

Run the QA checklist, including social previews and asset routing.

### Step 6 — Publication

Deploy to the client's domain or a NEXOLAB-managed domain.

### Step 7 — Handover

Provide the artist with the operational workflow for updating works and availability.

## Success criterion

A new artist should be launchable through configuration and controlled visual adaptation, without duplicating the entire Renée codebase.
