# Case 01 — Renée Figuera

## Role in the system

Renée Figuera is the first real implementation of the Artist Gallery System.

## What this case validates

- immersive hero presentation
- editorial exhibition layout
- dynamic artwork catalog
- availability states
- direct WhatsApp contact
- social sharing metadata
- Netlify deployment
- Google Sheets as lightweight catalog source

## What remains to validate

- configuration-only artist replacement
- second artist implementation
- repeatable onboarding
- repeatable publication checklist
- international configuration

## Strategic value

This project should be treated as the laboratory from which the reusable system is extracted. Changes that are specific to Renée remain case-specific; improvements that generalize become system capabilities.
