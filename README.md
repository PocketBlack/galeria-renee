# Galería Renée

> Experiencia digital premium para una artista visual, diseñada para transformar su presencia online en una galería profesional de presentación, exhibición y adquisición de obras originales.

## Propósito del proyecto

Este proyecto constituye la primera implementación de un sistema reutilizable de experiencias digitales profesionales para artistas visuales.

La base desarrollada para Renée Figuera será auditada, documentada y convertida progresivamente en una arquitectura modular que permita adaptar la experiencia a distintos artistas, manteniendo una base técnica y estratégica común y personalizando identidad, narrativa, catálogo, obras, información comercial y canales de contacto.

## Visión del sistema

Construir un servicio de presencia digital para artistas que permita exponer su obra profesionalmente en Uruguay y, posteriormente, ampliar su alcance internacional comenzando por España.

### Principio de reutilización

**Una arquitectura base → múltiples artistas → adaptaciones controladas.**

La intención no es reconstruir cada sitio desde cero, sino identificar qué componentes son estructurales, cuáles son configurables y cuáles deben personalizarse para cada artista.

## Componentes iniciales

- Experiencia visual editorial y premium.
- Hero inmersivo.
- Exposición principal de obras destacadas.
- Catálogo completo de obras.
- Fichas de obra y estado de disponibilidad.
- Integración dinámica con catálogo mediante Google Sheets/CSV.
- Conversión directa mediante WhatsApp.
- Diseño responsive.
- SEO básico.
- Canonical URL.
- Open Graph para distribución social.
- Twitter Cards.
- Favicon y recursos de identidad.

## Próxima etapa

Auditar la implementación actual de Renée para separar:

1. **Core del sistema** — componentes reutilizables.
2. **Configuración del artista** — datos, identidad y contenido.
3. **Capa visual** — dirección artística y personalización.
4. **Capa comercial** — contacto, adquisición y disponibilidad.
5. **Capa técnica** — SEO, Open Graph, rendimiento, accesibilidad y compatibilidad con crawlers.
6. **Proceso de implementación** — metodología replicable para nuevos clientes.

## Objetivo

Convertir esta implementación en una base de producto/servicio replicable para artistas que quieran presentar y comercializar profesionalmente su obra desde Uruguay hacia el mercado internacional.
